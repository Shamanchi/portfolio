# Runbook: стоимость и лимиты

## Цель

Демонстрация навыков не должна требовать платной подписки для базовой
проверки. Внешние сервисы и облака допустимы как опциональная часть, но
никогда не являются обязательным условием зелёного CI или зелёного локального
гейта.

## Правила по умолчанию

- Базовая проверка каждого проекта локальная: без платного аккаунта, без
  домена, без внешней базы данных.
- Внешние ключи — только через переменные окружения (см. SECRETS_RUNBOOK.md).
- CI по умолчанию не вызывает платные сервисы.
- Модельная и сервисная части спроектированы за интерфейсом провайдера:
  тесты и CI работают на фейковом провайдере без сети; реальный сервис
  подключается опционально по ключу.

## Лимиты прогонов роя

Прогоны портфолио проходят по каталогу, закрываются проекты по одному, и
каждый требует одобрения пользователя. Если сессия упирается в лимит времени
или объёма:

1. Работа останавливается на текущей задаче.
2. Оркестратор докладывает по-русски: что готово, что принято, что осталось
   и с какого места продолжать.
3. Качество не срезается: незавершённый проект не закрывается «как есть».

## Что делать, когда проект упирается в платный сервис

Проект источника может требовать платного облака без бесплатного тарифа.
Тогда по правилам каталога проект помечается статусом [-] с причиной, и
работа продолжается следующим проектом из каталога. Замена берётся из
следующего батча.

## Отчётность

Стоимость и трудозатраты каждой волны/батча фиксируются в .swarm/. В
публичный репозиторий отчёты не попадают.
