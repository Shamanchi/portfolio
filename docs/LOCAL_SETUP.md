# Инструкция локального запуска

Проверка портфолио с нуля на чистой Windows-машине.

## Что потребуется

- Git.
- Node.js 24 или новее (вместе с npm).
- GitHub CLI (gh) — только для публикации, для локальной проверки не нужен.

## Первый запуск

1. Склонировать репозиторий.
2. В корне репозитория выполнить npm ci.
3. Выполнить npm run gate.

Команда gate проверяет:

- типы всех проектов под папкой projects/ (там, где есть скрипт typecheck);
- тесты всех проектов (там, где есть скрипт test);
- секреты по всему дереву репозитория.

Успешный вывод заканчивается строками:

- secrets scan: ok (...)
- quality gate: PASS

## Отдельный проект

Каждый проект самодостаточен:

1. cd projects/имя-проекта
2. npm ci
3. npm run verify

Назначение команд и необязательные сетевые шаги описаны в README проекта.

## Проверка секретов отдельно

npm run secrets — быстрый прогон без прогона типов и тестов.

## Публикация

Публикация делается только после явного подтверждения пользователя и
включает: gh repo create в аккаунте Shamanchi, push main, проверку, что
Actions зелёные. До подтверждения никаких сетевых действий с репозиторием
не выполняется.
