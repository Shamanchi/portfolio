# Стек и опыт

Профиль автора (Pavel Yrevich, github.com/Shamanchi). Документ описывает, что
портфолио демонстрирует и на чём основан опыт.

## Инфраструктура и доставка

- Инфраструктура как код: Terraform, OpenTofu.
- Контейнеры: Docker, компоновка многосервисных приложений.
- Оркестрация: Kubernetes (K8s), кластеры и манифесты, Helm, Argo CD.
- Конвейеры: GitHub Actions, Jenkins, Azure DevOps, AWS CodePipeline, GitLab CI.
- Облака: AWS (VPC, ECS, S3, Lambda, DynamoDB) и Azure (AKS, DevOps).
- Наблюдаемость: метрики, логи, трейсы, OpenTelemetry.
- Безопасность разработки: DevSecOps, сканирование уязвимостей, supply chain.

## Программирование

- TypeScript строгий, без any; Node.js для CLI и тестов.
- PowerShell для автоматизации Windows: обслуживание, планировщик, фоновые
  задачи, самопроверки скриптов.
- Электронные настольные приложения: Electron + React + IPC, шифрование
  (AES-256-GCM), локальные хранилища.

## Искусственный интеллект

- Агенты и многоагентные конвейеры: планировщик, исполнитель, критик.
- RAG: построение индекса, гибридный поиск, оценка качества ответов.
- Модели за интерфейсом провайдера: по умолчанию фейковый провайдер без сети,
  реальный — опционально по ключу из окружения.
- Харнесс оценки качества: рубрики, проверка устойчивости судьи.
- Кэш-оптимизация запросов к LLM: локальный прокси, перенос динамики в конец
  промпта, экономия токенов.

## Принципы

- Windows-first: проекты запускаются на Windows, ничего не требует платного
  аккаунта для базовой проверки.
- Одна команда проверяет всё: типы, тесты, секреты.
- Внешние облака и API допустимы как демонстрация, но базовый путь работает
  без ключей и без оплаты.
- Каждый проект самодостаточен: свой README, свои тесты, свой шаг в CI.
